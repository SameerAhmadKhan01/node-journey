# http server task

### description

Build a simple HTTP Server with following features

1. GET : `/` : Send Simple hello from server message
2. GET : `/contact-us` : send ur email and contact to user
3. POST : `/tweet` : do a fake db opr and send that it is done
4. GET : `/tweet` : send all tweets from fake db to user

also u need to log the incoming req with timestamps in file named 'log.txt'
